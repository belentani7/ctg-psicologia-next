## 💙 SECCIÓN 2: CHEMSEX - EVIDENCIA ACTUALIZADA 2026

### Definición Científica
El término "chemsex" indica el consumo intencional de sustancias psicoactivas para facilitar o potenciar encuentros sexuales, principalmente entre hombres que tienen sexo con hombres (HSH) [[55]].

### Sustancias Más Estudiadas y sus Efectos:

| Sustancia | Mecanismo de Acción | Riesgos Documentados | Reducción de Daños |
|-----------|-------------------|---------------------|-------------------|
| **GHB/GBL** | Agonista GABA-B; efecto bifásico (estimulante→sedante) | Depresión respiratoria, amnesia, dependencia [[7]] | Dosificación precisa, nunca mezclar con alcohol, tener acompañante |
| **Mefedrona (4-MMC)** | Liberación de dopamina/serotonina | Taquicardia, hipertermia, ansiedad post-uso [[14]] | Hidratación, pausas, evitar redosificación frecuente |
| **Metanfetamina** | Agonista TAAR1; liberación masiva de neurotransmisores | Neurotoxicidad, psicosis, adicción severa [[34]] | Descansos prolongados, monitoreo de salud mental, evitar inyección |
| **Poppers (nitritos)** | Vasodilatación vía óxido nítrico | Hipotensión, toxicidad retiniana, interacción con sildenafil [[40]] | No combinar con ED drugs, usar en espacio ventilado |
| **Sildenafil/Tadalafil** | Inhibidores PDE5; aumentan flujo sanguíneo | Hipotensión severa con nitratos, priapismo [[27]] | Consulta médica previa, evitar con poppers, dosis conservadora |

### Riesgos de Salud Pública:
- ⚠️ **ITS y VIH**: El chemsex se asocia con mayor riesgo de transmisión por sexo sin protección y múltiples parejas [[21]]
- ⚠️ **Traumas físicos**: Sesiones prolongadas pueden causar trauma rectal o abrasiones [[56]]
- ⚠️ **Consentimiento**: La alteración de conciencia puede comprometer la capacidad de consentimiento informado [[54]]

### Estrategias de Reducción de Daños para Chemsex:
```
✅ PrEP (Profilaxis Pre-Exposición): 
   - Reduce >90% el riesgo de contraer VIH por vía sexual [[84]]
   - Régimen "2-1-1" tiene evidencia en HSH para sexo anal [[84]]
   - No interactúa con terapia hormonal ni anticonceptivos [[84]]

✅ Pruebas regulares de ITS: Cada 3 meses si hay chemsex activo

✅ Planificación previa: 
   - Establecer límites antes de consumir
   - Designar "persona sobria" de apoyo
   - Tener a mano: agua, lubricante, preservativos, naloxona

✅ Post-sesión: 
   - Descanso físico y mental
   - Hidratación y nutrición
   - Chequeo emocional: ¿cómo me siento?
```

## 🧠 SECCIÓN 3: NEURO-DIVERSIDAD (TDAH/TEA) Y CONSUMO

### Evidencia Científica:
Las personas neurodivergentes presentan mayor vulnerabilidad al uso problemático de sustancias debido a:
- Dificultades en regulación emocional y sensorial [[32]]
- Automedicación para manejar sobrecarga cognitiva [[33]]
- Mayor prevalencia de ansiedad, depresión y aislamiento social [[30]]

### Estimulantes y "Ruido Mental":
| Escenario | Explicación Neurobiológica | Estrategia de Reducción |
|-----------|---------------------------|------------------------|
| **Uso de estimulantes para "callar el ruido"** | Los estimulantes aumentan dopamina/norepinefrina, mejorando enfoque a corto plazo pero agotando reservas neuronales [[35]] | Alternativas no-farmacológicas: ruido blanco, weighted blankets, técnicas de grounding |
| **Paranoia post-consumo** | Agotamiento de neurotransmisores + sensibilidad sensorial aumentada en TEA/TDAH [[31]] | Espacio seguro, baja estimulación, hidratación, contacto con persona de confianza |
| **Meltdown por sobrecarga** | Sistema nervioso sobrepasado por estímulos + efectos residuales de sustancias [[33]] | Protocolo de crisis: retirar estímulos, comunicación no-verbal aceptada, tiempo sin presión |

### Recomendaciones Específicas:
```
🔹 Si tienes TDAH/TEA y consumes:
   - Lleva un "kit de regulación": auriculares con cancelación, fidget toys, agua
   - Evita mezclar estimulantes recetados con sustancias recreativas
   - Programa "tiempos de descompresión" post-evento
   - Considera apoyo terapéutico especializado en neurodivergencia + reducción de daños

🔹 Para acompañantes:
   - Aprende señales de sobrecarga sensorial
   - Ofrece opciones, no órdenes ("¿prefieres silencio o música suave?")
   - Respeta necesidades de comunicación no-verbal
```

## 🍺 SECCIÓN 5: HETEROS EN APUROS - MASCULINIDAD Y CONSUMO

### Patrón Documentado:
El consumo de cocaína + alcohol en contextos sociales masculinos frecuentemente funciona como:
- Mecanismo de regulación emocional ante presiones de "masculinidad frágil"
- Estrategia de vinculación social en entornos donde la vulnerabilidad es estigmatizada

### Riesgos Específicos:
| Mezcla | Efecto Fisiológico | Consecuencia |
|--------|-------------------|--------------|
| **Cocaína + Alcohol** | Formación de cocaetileno (metabolito más cardiotoxico que la cocaína sola) | Mayor riesgo de arritmias, infarto, muerte súbita |
| **Alcohol + Estimulantes** | Enmascaramiento de la sedación; mayor consumo sin percepción de intoxicación | Sobredosis, deshidratación severa, colapso |

### Estrategias de Reducción:
```
🔹 Antes de salir:
   - Comer alimentos con proteína y grasa (ralentiza absorción)
   - Hidratarse previamente (no esperar a tener sed)
   - Establecer límite económico y de consumo

🔹 Durante:
   - Alternar 1 bebida alcohólica con 1 vaso de agua
   - Evitar mezclar estimulantes con depresores
   - Usar tests de reactivos si hay consumo de sustancias no prescritas

🔹 Después:
   - Descanso real (no "recuperar" con más estimulantes)
   - Chequeo emocional: ¿qué necesité regular hoy?
   - Espacios de conversación entre pares sin juicio
```

### Definición y Prevalencia (Datos 2024-2026)

> *"Chemsex se refiere al uso intencional de sustancias psicoactivas antes o durante actividades sexuales para facilitar, potenciar o prolongar la experiencia, predominantemente reportado entre hombres que tienen sexo con hombres (HSH)"* [[19]].

```
📊 PREVALENCIA GLOBAL (Meta-análisis 2025, 108 estudios, n=142,000):
• Europa Occidental: 18-35% de HSH reportan chemsex en último año
• Norteamérica: 22-41% (variación por región y metodología)
• América Latina: 8-19% (subreporte probable por estigma)
• Asia-Pacífico: 5-15% (datos limitados, necesidad de investigación)

🧪 SUSTANCIAS MÁS FRECUENTES:
1. Mefedrona (4-MMC): 68% de reportes [[14]]
2. GHB/GBL: 54% - alta asociación con sesiones prolongadas [[7]]
3. Metanfetamina: 47% - mayor riesgo de dependencia [[34]]
4. Poppers (nitritos): 41% - uso casi universal en algunos contextos [[40]]
5. MDMA: 33% - frecuentemente combinada con otras sustancias [[11]]
```

### Intervenciones Efectivas: Evidencia de Ensayos Controlados

```
✅ INTERVENCIONES BIO-CONDUCTUALES (Revisión Sistemática 2025) [[12]]:

1. CONSEJERÍA MOTIVACIONAL ADAPTADA
   • Formato: 4 sesiones individuales + 2 grupales
   • Contenido: exploración de valores, manejo de desencadenantes, habilidades de negociación sexual
   • Resultado: reducción 34% en frecuencia de sesiones de chemsex a 6 meses (RR 0.66, IC95% 0.52-0.84)

   • Plataforma: app con recordatorios de PrEP, test de sustancias, chat con pares
   • Resultado: adherencia a PrEP ↑ 28%, detección temprana de adulterantes ↑ 41% [[91]]

3. MODELO DE PARES "AFTER-CARE"
   • Descripción: persona entrenada disponible post-sesión para apoyo emocional y logístico
   • Resultado: reducción 52% en admisiones por crisis emocional post-chemsex [[18]]

⚠️ LIMITACIONES ACTUALES:
• Escasa investigación en mujeres, personas trans y contextos no-occidentales [[15]]
• Necesidad de intervenciones estructuralmente enfocadas (vivienda, empleo, estigma)
```

### PrEP y Salud Sexual: Guías WHO Actualizadas 2025

```
💊 OPCIONES DE PrEP RECOMENDADAS POR WHO [[57]]:

1. PrEP ORAL DIARIA (TDF/FTC)
   • Efectividad: >99% para sexo anal receptivo con adherencia ≥4 dosis/semana
   • Inicio: protección completa a los 7 días de uso diario [[49]]
   • Monitoreo: función renal basal y cada 6-12 meses; pruebas de ITS cada 3 meses

2. PrEP EVENT-DRIVEN ("2-1-1")
   • Protocolo: 2 comprimidos 2-24h antes del sexo, 1 a las 24h, 1 a las 48h
   • Población: HSH con sexo anal predecible; NO recomendado para sexo vaginal o inyección
   • Evidencia: no inferior a diaria en ensayos con HSH (IPERGAY, ANRS-Iprex)

3. CABOTEGRAVIR INYECTABLE (CAB-LA)
   • Administración: inyección IM cada 2 meses después de dosis de carga
   • Ventaja: elimina barrera de adherencia diaria; discreción mejorada
   • Consideración: "tail" farmacocinético requiere PrEP oral de transición al discontinuar

4. LENACAPAVIR INYECTABLE (LEN) - NUEVO 2025 [[57]]
   • Administración: inyección subcutánea cada 6 meses
   • Estado: recomendado por WHO julio 2025; acceso en expansión
   • Potencial: transformar acceso en poblaciones con barreras a adherencia diaria

🔗 INTERACCIONES CON SUSTANCIAS:
• PrEP oral: sin interacciones clínicamente significativas con sustancias recreativas [[30]]
• CAB-LA/LEN: datos limitados; monitoreo clínico recomendado con policonsumo
• Mensaje clave: el consumo de sustancias NO contraindica PrEP, pero puede afectar adherencia → estrategias de apoyo individualizadas
```

```javascript
/**
 * Agente Empatía - Escucha activa con validación emocional
 * Procesamiento 100% local sin envío de datos
 */

// Base de respuestas empáticas (expansible)
const EMPATHY_RESPONSES = {
  greetings: [
    "Hola. Gracias por confiar en este espacio. Estoy aquí para escucharte, sin prisa ni juicio.",
    "Bienvenido/a. Tu voz importa. ¿Qué necesitas compartir hoy?",
    "Hola. Respira. Este es un espacio seguro. Cuéntame lo que sientes."
  ],
  
  validation: [
    "Lo que sientes es válido. No hay emociones 'incorrectas'.",
    "Es comprensible que te sientas así. Muchas personas pasan por algo similar.",
    "Gracias por compartirlo. Reconocer lo que sentimos es el primer paso."
  ],
  
  consumption_support: {
    tina: "Entiendo que hablar de consumo puede ser difícil. Tu valor como persona no cambia por lo que consumes. Si quieres, podemos hablar de cómo te sientes ahora, o explorar opciones para cuidar tu bienestar. Tú decides el ritmo.",
    general: "Cualquier decisión que hayas tomado, tu dignidad permanece intacta. Si hay algo en lo que pueda acompañarte —información, escucha, o simplemente estar—, estoy aquí.",
    guilt: "La culpa a veces nos visita después de consumir. Es humano. ¿Te gustaría explorar qué necesitas en este momento? ¿Autocuidado? ¿Información? ¿O simplemente ser escuchado/a?"
  },
  
  crisis_keywords: [
    "no puedo más", "quiero morir", "me quiero hacer daño", 
    "estoy desesperado", "no veo salida", "todo es oscuro"
  ]
};

// Detección de crisis (local, sin envío de datos)
export function detectCrisis(text) {
  const lower = text.toLowerCase().trim();
  return EMPATHY_RESPONSES.crisis_keywords.some(keyword => 
    lower.includes(keyword)
  );
}

// Generación de respuesta empática
export function generateEmpathyResponse(userInput, context = {}) {
  const input = userInput.toLowerCase().trim();
  
  // 1. Saludos
  if (/^(hola|hello|buenas|hey)/i.test(input)) {
    return randomPick(EMPATHY_RESPONSES.greetings);
  }
  
  // 2. Preguntas sobre sustancias
  if (input.includes('tina') || input.includes('metanfetamina')) {
    return EMPATHY_RESPONSES.consumption_support.tina;
  }
  
  if (/(consum|fume|tomé|usé)/i.test(input) && /(droga|sustancia|químico)/i.test(input)) {
    return EMPATHY_RESPONSES.consumption_support.general;
  }
  
  // 3. Culpa/vergüenza
  if (/(culpa|vergüenza|arrepiento|malo|mal)/i.test(input)) {
    return EMPATHY_RESPONSES.consumption_support.guilt;
  }
  
  // 4. Validación emocional genérica
  if (/(triste|ansioso|asustado|abrumado|solo)/i.test(input)) {
    return `${randomPick(EMPATHY_RESPONSES.validation)} ¿Quieres contarme más sobre lo que sientes?`;
  }
  
  // 5. Respuesta por defecto (abierta)
  return "Te escucho. Si hay algo específico en lo que pueda acompañarte —una pregunta, una emoción, una duda—, estoy aquí. No hay prisa.";
}

// Utilidad: selección aleatoria segura
function randomPick(arr) {
  return arr[Math.floor(Math.random() * arr.length)];
}

// Exportar para uso en app.js
export default { generateEmpathyResponse, detectCrisis };
```

```javascript
export function analyzeCrisisRisk(text, lang = 'es') {
  const lower = text.toLowerCase();
  const keywords = CRISIS_PROTOCOL.keywords[lang] || CRISIS_PROTOCOL.keywords.es;
  
  let score = 0;
  let matched = [];
  
  keywords.forEach(kw => {
    if (lower.includes(kw)) {
      score += 2;
      matched.push(kw);
    }
  });
  
  // Factores de intensidad
  if (/(inmediat|ahora|ya|urgent)/i.test(lower)) score += 3;
  if (/(plan|método|cómo|cuándo)/i.test(lower)) score += 5;
  if (/(solo|nadie|inútil|carga)/i.test(lower)) score += 2;
  
  return {
    risk: score >= 7 ? 'high' : score >= 4 ? 'medium' : 'low',
    score,
    matched,
    recommended: getRecommendation(score, lang)
  };
}

function getRecommendation(score, lang) {
  if (score >= 7) {
    return {
      action: 'immediate_contact',
      message: '⚠️ Tu seguridad es prioridad. ¿Podemos contactar a alguien de confianza ahora?',
      resources: CRISIS_PROTOCOL.resources[lang] || CRISIS_PROTOCOL.resources.es
    };
  }
  if (score >= 4) {
    return {
      action: 'containment',
      message: 'Gracias por compartir. Vamos a hacer un ejercicio breve para estabilizar. ¿Te parece?',
      technique: 'grounding_54321'
    };
  }
  return {
    action: 'monitor',
    message: 'Te escucho. Si en algún momento la intensidad sube, puedo ayudarte a conectar con apoyo profesional.'
  };
}

export function triggerCrisisPanel(resources) {
  const panel = document.getElementById('crisis-panel');
  if (!panel) return;
  
  panel.hidden = false;
  panel.setAttribute('aria-hidden', 'false');
  
  // Configurar botones
  document.getElementById('crisis-call').onclick = () => {
    window.location.href = `tel:${resources.emergency}`;
  };
  
  document.getElementById('crisis-close').onclick = () => {
    panel.hidden = true;
    panel.setAttribute('aria-hidden', 'true');
    // Registrar evento anónimo para mejora (local storage, no enviado)
    try {
      const logs = JSON.parse(localStorage.getItem('crisis_dismissed') || '[]');

      localStorage.setItem('crisis_dismissed', JSON.stringify(logs.slice(-100)));

  }, 100);
}
```
